# PlateMate

WDD 330 Final Project — a web application for searching recipes, viewing nutritional information, and building a weekly meal plan.

## APIs Used

- Spoonacular API — recipe search, ingredients, instructions
- USDA FoodData Central API — nutritional breakdown (calories, protein, fat, carbs, etc.)

## Data Storage

- localStorage — saved meal plans, favorite recipes, user preferences

## Common Workflow Commands

- `npm run start` — starts local dev server
- `npm run lint` — run ESLint
- `npm run format` — run Prettier
- `npm run build` — build for production
